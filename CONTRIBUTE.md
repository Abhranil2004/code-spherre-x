# 🚀 Contributing to Code-Spherre-X  

We welcome all contributions! Whether you're fixing a bug, adding a feature, or improving documentation, your help is appreciated.  

## 📝 How to Contribute  

### 🔹 Project List Contribution  

> No need to clone the repo! You can directly edit files using the **GitHub Online File Editor**.  

1. **Check for duplicates** – Ensure the project/tutorial you're adding **doesn’t already exist** and is of **high quality** (clean code, relevant scope).  
2. **Update `data.json`** – Add your project details in the [`data.json`](#) file. **Only direct links** to the tutorial are allowed (No URL shorteners).  

### 🔹 Feature Contribution
